Privacy Policy — Ambient Uploader

Last updated: October 13, 2026

Who uses this app

Ambient Uploader is a private, single-user tool. Its only user is its owner and developer. It is not offered to the public and no other person's data is collected, requested, or processed.

Google user data the app accesses

With the owner's authorization, the app accesses the YouTube Data API and YouTube Analytics API for the owner's own channels. This includes the ability to upload videos the owner created, set their titles, descriptions, thumbnails and playlist membership, post a channel comment on the owner's own Shorts, and read the owner's own channel and video statistics.

How the data is used

Google user data is used only to carry out the owner's own publishing and reporting tasks described above. It is not used for advertising, profiling, or any purpose unrelated to operating the owner's own YouTube channels.

How the data is stored

The app's OAuth refresh token is stored only in a private configuration file on the owner's own computer, protected by file permissions (mode 0600). It is not sent to any third party, not stored in a public or shared location, and not included in any publication. No Google user data is stored on any external server.

How the data is shared

No Google user data is sold, shared, transferred, or disclosed to any third party. Data is sent only to Google's own APIs, at the owner's direction, to publish and manage the owner's own content.

Limited Use

Ambient Uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Because no user data is stored outside the owner's own computer, revoking access and deleting the local configuration file removes all retained Google user data.
